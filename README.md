# 📚 FocusFlow

> A simple and interactive study planner designed to help students organize their study sessions, set priorities, and track their daily progress.

🌐 **Live Demo:** https://focusflow-study-planner-psi.vercel.app/

📦 **Source Code:** https://github.com/spideybuild/focusflow-study-planner

---

## ✨ Features

- 📖 Add and manage study sessions
- 🎯 Set priorities for each session
- ⏱️ Choose study duration
- 📊 Track daily study progress
- 🧹 Clear study sessions when needed
- 🐻 Interactive mascot with animations
- ✨ Smooth and engaging UI animations
- 📱 Responsive design for different screen sizes

---

## 🛠️ Built With

- **HTML5** — Structure and content
- **CSS3** — Styling, layout, animations, and responsive design
- **JavaScript** — Interactions, session management, and progress tracking
